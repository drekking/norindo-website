# Norindo website

Norwegian-language website connecting Indonesian coffee producers with Norwegian roasteries. Restored from the November 2, 2026 Norindo page.

## Files

- `index.html`: complete responsive website, including styles and inline illustration.
- `.nojekyll`: serves static files without Jekyll processing on GitHub Pages.

No dependencies, build command, external fonts, scripts or image services are required. Contact buttons open email and WhatsApp.

## Publishing

Source uploaded; hosting and domain migration are not yet configured.

For GitHub Pages, open Settings > Pages, choose Deploy from a branch, then main and / (root), and Save. Private repository publishing requires an eligible paid GitHub plan. GitHub Free requires a public repository. Do not change repository visibility without the owner's decision.

Verify the provider's temporary site URL before connecting norindo.com. Configure the custom domain in the chosen hosting service before replacing the old website DNS records at Squarespace. Preserve mail-related DNS records. No DNS changes were made during this restoration.
